# NooshaFocus — ستاره‌ی تمرکز نوشا 🌷

پروژه‌ی کامل سورس اندروید با **Kotlin، Jetpack Compose و Material 3**، طراحی فارسی کودکانه و انیمیشن مشق‌نویسی.

## امکانات

- تایمر تمرکز با انتخاب ۱۰، ۱۵ یا ۲۰ دقیقه
- استراحت با انتخاب ۳، ۵ یا ۷ دقیقه
- شروع، مکث و بازنشانی تایمر
- دریافت یک ستاره پس از پایان کامل هر دوره‌ی تمرکز
- ذخیره‌ی دائمی مجموع ستاره‌ها و تعداد دوره‌های تکمیل‌شده با `SharedPreferences`
- ذخیره‌ی زمان تمرکز و استراحت انتخاب‌شده
- هدف روزانه‌ی ۴ ستاره با نوار پیشرفت؛ شمارنده‌ی روزانه با تغییر تاریخ روز صفر می‌شود
- بازنشانی آمار با پنجره‌ی تأیید
- انیمیشن دفتر و مداد برای تشویق کودک به نوشتن مشق
- انتخاب فایل موسیقی از گوشی، پخش، مکث و توقف
- فایل موسیقی پیش‌فرض در `app/src/main/res/raw/focus_music.m4a`
- رابط راست‌چین، رنگ‌های ملایم، کارت‌های گرد و دکمه‌های بزرگ
- بدون نیاز به اینترنت هنگام اجرای برنامه؛ اینترنت برای دریافت وابستگی‌ها و ساخت اولیه لازم است

## پیش‌نیازها

- Android Studio نسخه‌ی سازگار با Android Gradle Plugin 8.7.3
- JDK 17
- Android SDK Platform 35
- اتصال اینترنت برای اولین Gradle Sync

## باز کردن و ساخت APK

1. فایل ZIP را استخراج کنید.
2. در Android Studio گزینه‌ی **Open** را بزنید و پوشه‌ی `NooshaFocusTimer` را انتخاب کنید.
3. صبر کنید **Gradle Sync** کامل شود.
4. از منوی **Build → Build Bundle(s) / APK(s) → Build APK(s)** استفاده کنید.
5. APK دیباگ معمولاً در مسیر زیر ساخته می‌شود:

   `app/build/outputs/apk/debug/app-debug.apk`

این بسته سورس کامل پروژه است و APK از پیش‌ساخته‌شده در آن قرار ندارد؛ برای تولید APK باید Android Studio و Android SDK روی سیستم موجود باشند.

## نکته‌های رفتاری

- هر بار که تایمرِ دوره‌ی تمرکز به صفر برسد، یک ستاره و یک دوره به آمار اضافه می‌شود و تایمر وارد استراحت می‌شود.
- اتمام استراحت به‌تنهایی ستاره نمی‌دهد و تایمر را به دوره‌ی تمرکز بعدی می‌برد.
- ستاره‌ها و تعداد کل دوره‌ها بین اجراهای برنامه باقی می‌مانند.
- هدف روزانه بر اساس تاریخ محلی دستگاه محاسبه می‌شود.
- تایمر در صورت بسته‌شدن اجباری برنامه از همان ثانیه ادامه پیدا نمی‌کند؛ فقط امتیازها و تنظیمات ذخیره می‌شوند.
- انتخاب موسیقی دلخواه در وضعیت فعلی تا زمان اجرای جاری نگه داشته می‌شود؛ فایل موسیقی پیش‌فرض در منابع برنامه باقی است.
- موسیقی را با صدای کم پخش کنید و اگر باعث حواس‌پرتی شد، خاموشش کنید. این اپ ابزار کمکی برنامه‌ریزی است و جایگزین ارزیابی یا درمان تخصصی ADHD نیست.
