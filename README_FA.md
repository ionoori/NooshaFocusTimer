# ستاره‌ی تمرکز — تایمر تکالیف کودک

پروژه‌ی سورس اندروید با Kotlin و Jetpack Compose، رابط فارسی و طراحی کودکانه.

## امکانات
- زمان تمرکز ۱۰، ۱۵ یا ۲۰ دقیقه
- استراحت ۳، ۵ یا ۷ دقیقه
- شروع، مکث و بازنشانی تایمر
- دریافت یک ستاره پس از پایان هر جلسه تمرکز
- ملودی ساده و آرامِ تولیدشده داخل برنامه؛ بدون نیاز به اینترنت یا فایل صوتی
- رابط رنگی، دکمه‌های بزرگ و پیام‌های تشویقی

## ساخت APK
1. ZIP را استخراج کنید.
2. پوشه‌ی `NooshaFocusTimer` را در Android Studio باز کنید.
3. Gradle Sync را کامل کنید (دریافت وابستگی‌ها به اینترنت نیاز دارد).
4. از مسیر **Build > Build Bundle(s) / APK(s) > Build APK(s)** فایل APK را بسازید.
5. مسیر معمول خروجی: `app/build/outputs/apk/debug/app-debug.apk`

این فایل شامل سورس پروژه است، نه APK آماده. برای ساخت APK به Android Studio و Android SDK نیاز دارید. ملودی تولیدشده ساده است و موسیقی ضبط‌شده نیست؛ صدا را کم نگه دارید و اگر باعث حواس‌پرتی شد خاموشش کنید. این اپ ابزار کمکی برنامه‌ریزی است و جایگزین ارزیابی یا درمان تخصصی ADHD نیست.

## انتخاب موسیقی دلخواه
در نسخه‌ی به‌روزشده، از بخش «آهنگ‌های من» روی «انتخاب آهنگ» بزنید و فایل صوتی موجود روی گوشی را انتخاب کنید. سپس «پخش» یا «مکث» را بزنید. اگر آهنگی انتخاب نشده باشد، دکمه‌ی پخش، ملودی آرام داخلی برنامه را اجرا می‌کند. صدای موسیقی را پایین نگه دارید؛ در صورت حواس‌پرتی، سکوت ممکن است بهتر باشد.

## ساخت آنلاین در GitHub Actions
فایل `app/build.gradle.kts` تنظیم JVM 17 برای Java و Kotlin را دارد. فایل‌های داخل پوشه‌ی `NooshaFocusTimer` را در ریشه‌ی مخزن GitHub قرار دهید. فایل گردش‌کار ساخت باید در مسیر `.github/workflows/android-apk.yml` باشد.

## موسیقی همراه برنامه
فایل موسیقی کاربر در `app/src/main/res/raw/focus_music.m4a` قرار داده شده و به‌صورت پیش‌فرض داخل برنامه پخش می‌شود؛ بنابراین برای آهنگ پیش‌فرض، اینترنت یا انتخاب دستی فایل لازم نیست. از گزینه «انتخاب آهنگ» نیز می‌توان فایل صوتی دیگری را از گوشی برگزید. این فایل صوتی 8 دقیقه و 54 ثانیه است و در پخش برنامه تکرار می‌شود.
